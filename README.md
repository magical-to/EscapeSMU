# SMU : 캠퍼스 한 바퀴 🏫

**SMU : 캠퍼스 한 바퀴**는 상명대학교 천안캠퍼스 학생들을 위한 **캠퍼스 탐방 어플리케이션**입니다.  
본 프로젝트는 **상명대학교 소프트웨어학과 졸업작품**으로 개발되었으며,  
처음 캠퍼스에 방문한 신입생이나 방문객들이 **효율적으로, 재미 요소들을 가지고 학교를 둘러볼 수 있도록** 설계되었습니다.

![SMUEscape](https://github.com/user-attachments/assets/3e39e7b1-db02-4fc6-9375-4e256e4774dc)

## 📱 주요 기능

- **캠퍼스 주요 지점 소개**  
  학교 건물, 편의시설 등 캠퍼스 내 다양한 시설 안내

- **위치 기반 길찾기**  
  현재 위치를 기준으로 주요 장소 확인 가능

- **미션 탐방 기능**  
  특정 장소를 방문하면 이미지 인식, 음성 인식 및 다양한 기믹을 수행하는 기능

- **UI/UX 중심 설계**  
  친숙한 디자인과 직관적인 사용자 흐름으로 누구나 쉽게 이용 가능

## 🛠 기술 스택

- **React Native**  
- **Expo**  
- **Firebase (Auth / Firestore / Storage)**  
- **Kakao Map API**  
- **Android / iOS 크로스 플랫폼 지원**
